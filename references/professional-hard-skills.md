# 专业硬核（地基）

> 没有深厚的财务功底，其他一切无从谈起。

---

## 1. 会计准则与报告

### 核心能力
- 精通IFRS/GAAP，确保财务报告真实、合规、透明
- 三张报表勾稽关系穿透：利润表→资产负债表→现金流量表
- 熟练应对审计问询、监管检查
- **财务操纵识别**：识别收入提前确认、费用资本化操纵、关联交易粉饰

### 典型场景
> 公司毛利率突然上涨——是产品提价（积极），还是压缩研发费用资本化（操纵利润）？不懂会计深度的分析师容易误判。

### 红线清单
| 操纵手法 | 识别信号 |
|---------|---------|
| 收入提前确认 | 应收账款增速>营收增速 |
| 费用资本化操纵 | 资本化率异常波动 |
| 关联交易粉饰 | 关联方占比>20%且定价偏离市场 |
| 存货减值不足 | 存货周转天数持续上升 |

## 2. 高级财务建模与估值

### 核心能力
- 构建动态三表联动模型（利润表→资产负债表→现金流量表循环引用）
- DCF（现金流折现）模型：WACC估算、终值假设敏感性
- LBO（杠杆收购）模型：债务偿还计划、IRR计算
- 并购整合模型：合并报表预测、协同效应量化
- 情景分析：Best/Base/Worst + 敏感性矩阵

### 典型场景
> 收购标的：建立整合模型，预测5年合并报表的资产负债率、利息覆盖倍数，模拟"收入降10%"或"利率升2%"对现金流的影响。

### 建模自检清单
- [ ] 三表勾稽平衡（资产=负债+权益）
- [ ] 循环引用是否收敛
- [ ] 关键假设是否有据可依
- [ ] 敏感性分析覆盖核心变量
- [ ] 边界条件测试（极端值是否崩溃）

## 3. 税务筹划与法规

### 核心能力
- 转让定价策略与合规
- 合法优化整体税负（集团税务架构设计）
- 《证券法》《公司法》合规，防范法律风险
- 跨境税务：BEPS行动、双重征税协定、CFC规则

### 优化原则
- **合法性优先**：绝不为节税触碰法律红线
- **实质重于形式**：交易必须有真实商业目的
- **前瞻性**：税法变动预判+提前布局

## 4. 资金与风险管理

### 核心能力
- 现金流管理：经营/投资/融资三维度统筹
- 融资工具选择：债务/股权/绿色债券/可转债/ABS
- 汇率对冲：远期/期权/自然对冲
- 利率风险管理：IRS/FRA/久期匹配
- 流动性风险：压力测试、应急融资计划

### 风险管理框架
```
风险识别 → 风险度量(VaR/压力测试) → 风险应对(规避/转移/对冲/承受) → 监控与报告
```

## 5. 数字化与技术

### 核心能力
- ERP系统（SAP/Oracle）深度理解与优化
- 业财一体化：业务数据→财务数据的自动化流转
- 数据治理：主数据管理、数据质量、数据安全
- BI/AI应用：预测分析、异常检测、智能报表
- RPA：重复性财务流程自动化

### 转型路径
```
手工Excel → 系统化ERP → 业财一体 → 数据驱动 → AI智能决策
```
