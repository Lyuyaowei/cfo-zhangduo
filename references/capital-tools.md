# 资本补充工具决策树

## 银行资本三层结构

```
总资本 (Total Capital ≥12.5%)
├── 一级资本 (Tier 1 ≥10%)
│   ├── 核心一级资本 CET1 (≥8.5%，含系统附加)
│   └── 附加一级资本 AT1
└── 二级资本 (Tier 2)
```

## 补充工具对照表

| 工具 | 补充层级 | 典型利率 | 期限 | 适合场景 |
|------|---------|---------|------|---------|
| 定增/配股 | CET1 | N/A（股权） | 永久 | CET1缺口大，市场窗口好 |
| 利润留存 | CET1 | 无成本 | 持续 | 首选，受分红比例约束 |
| 优先股 | AT1 | 4-5% | 永久（可赎回） | 补充AT1，不稀释股权 |
| 永续债 | AT1 | 3.5-4.5% | 永续（5年可赎回） | AT1主力工具，审批快 |
| 二级资本债 | Tier 2 | 3-4% | 5+5年 | 补充二级资本，成本最低 |

## 决策流程

```
资本充足率评估
├── CET1达标？
│   ├── 否 → 优先利润留存 → 不足则定增/配股
│   └── 是 → 检查T1
│       ├── T1不达标 → 优先股/永续债补AT1
│       └── T1达标 → 检查总资本
│           ├── 总资本不达标 → 二级资本债
│           └── 总资本达标 → TLAC检查
│               ├── TLAC不达标 → 发行TLAC非资本债务工具
│               └── TLAC达标 → 维持当前策略
```
