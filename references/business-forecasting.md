# 企业经营状况预测 🧭

> 预测，本质上是连接**数据 × 业务逻辑 × 决策**的综合性工作。优秀CFO不做占卜师，做建筑师——用模型搭框架，让不确定性变得可量化、可沟通、可追踪。

---

## 一、四层能力模型

```
         ┌──────────────┐
         │  四、沟通协作  │ ← 心脏
         │  归因·汇报·协同│
         ├──────────────┤
         │  三、业务洞察  │ ← 大脑
         │  驱动因素·行业│
         ├──────────────┤
         │  二、建模能力  │ ← 骨架
         │  三表·工具·情景│
         ├──────────────┤
         │  一、财务基础  │ ← 语言
         │  三表勾稽·成本性态│
         └──────────────┘
```

### 第一层：财务基础（语言层）
**预测的"语言"。** 没有财务基础，模型脱离真实运行规则。

| 能力 | 内容 | 预测关联 |
|------|------|---------|
| 三表勾稽 | 利润表↔资产负债表↔现金流量表的联动逻辑 | 销售↑→应收账款↑→经营现金流↓（滞后） |
| 成本性态 | 固定成本（房租/折旧）vs 变动成本（原材料/直接人工） | 本量利分析：盈亏平衡点、安全边际 |
| 关键指标 | 毛利率、周转率、杠杆率、EBITDA | 用指标构建假设，而非拍脑袋 |

### 第二层：建模能力（骨架层）
**预测的"骨架"。** 将商业逻辑转化为可计算的模型。

| 能力 | 工具 | 适用场景 |
|------|------|---------|
| 三表联动模型 | Excel（OFFSET+命名范围+循环引用）| 季度/年度预测 |
| SQL数据提取 | 直接连ERP/CRM，不依赖导出 | 历史数据获取 |
| Python时间序列 | FORECAST.ETS、ARIMA | 大数据量预测 |
| 驱动因素建模 | 收入=客户数×客单价×复购率 | 结构化拆解 |

### 第三层：业务洞察（大脑层）
**预测的"灵魂"。** 决定模型是否接地气，而非空中楼阁。

| 商业模式 | 核心驱动因素 | 领先指标 |
|---------|------------|---------|
| 零售/快消 | 同店销售、客流量、转化率 | 进店人数、促销力度 |
| 制造业 | 产能利用率、订单backlog、原材料价格 | 询盘量、供应商交期 |
| SaaS | MRR、流失率、CAC、LTV | 新增线索、活跃度、流失预警 |
| 平台型 | 双边网络效应、GMV、抽佣率 | 用户留存、频次 |

### 第四层：沟通协作（心脏层）
**预测的"出口"。** 再好的模型，不沟通等于零。

| 场景 | 核心动作 | 关键原则 |
|------|---------|---------|
| 假设沟通 | 向销售/采购/生产负责人谈假设 | 用"前提是…"句式，让他们挑战假设 |
| 偏差归因 | 预测vs实际差异分析 | 区分：假设错误 vs 执行问题 vs 模型缺陷 |
| 汇报呈现 | 图表+关键结论+风险点 | 一页看全，支持决策 |

## 二、七步工作流

### Step 1：明确目的
**核心问题：** 是年度预算、融资尽调，还是月度滚动预测？

| 场景 | 时间跨度 | 颗粒度 | 精度要求 |
|------|---------|--------|---------|
| 年度预算 | 12个月 | 月度 | 中（允许±10%） |
| 融资预测 | 3-5年 | 年度 | 低（趋势为主） |
| 月度滚动 | 3-6个月 | 月度 | 高（允许±5%） |
| 并购模型 | 5年+ | 年度 | 中（协同效应需保守） |

### Step 2：收集历史数据
**核心任务：** 过去3-5年的收入、成本、运营数据。

```sql
-- 收入趋势（按月）
SELECT 
    DATE_TRUNC('month', sale_date) AS month,
    SUM(revenue) AS total_revenue,
    SUM(revenue) / COUNT(DISTINCT customer_id) AS avg_revenue_per_cust
FROM sales
WHERE sale_date >= DATE_SUB(CURRENT_DATE, INTERVAL 36 MONTH)
GROUP BY 1 ORDER BY 1;

-- 成本结构（按品类）
SELECT 
    product_line,
    SUM(cogs) AS total_cogs,
    SUM(cogs)/SUM(revenue) AS cogs_ratio
FROM financials
GROUP BY product_line;
```

### Step 3：建立假设
**核心原则：** 每个数字背后都要有人负责。

| 假设类型 | 访谈对象 | 常见假设区间 |
|---------|---------|------------|
| 收入增长率 | 销售负责人 | 5%-30%（视市场而定） |
| 毛利率变化 | 采购/产品 | ±2%的原材料价格波动 |
| 费用率 | 市场/人事 | 营销费占收入X% |
| 资本支出 | 生产/IT | 产能扩张计划 |

**假设记录模板：**
```
假设A：2026年收入增长15%（销售总监确认）
假设B：毛利率维持在38%（原材料价格稳定假设）
假设C：营销费用率控制在12%（预算上线）
前提条件：[任一假设偏离时的触发条件]
```

### Step 4：搭建模型
**三表联动结构：**

```
收入假设
  ↓
利润表（收入→成本→EBIT→净利润）
  ↓
资产负债表（应收账款↑、存货↑、固定资产折旧）
  ↓
现金流量表（经营现金流=净利润+折旧-营运资本变动）
  ↓
BALANCE CHECK：资产总计 = 负债+权益（必须平衡）
```

**驱动因素法的标准模板：**
```
收入 = 客户数 × 客单价 × 复购率
    = (新客 + 存量客) × (产品A客单 + 产品B客单) × (1 - 流失率)

成本 = 固定成本（租金+折旧+管理费用）
     + 变动成本（原材料+直接人工+运费）

利润 = 收入 - 成本
```

### Step 5：情景分析
**三情景标准结构：**

| 情景 | 假设设置 | 收入区间（示例） |
|------|---------|---------------|
| 乐观 | 市场回暖+提价成功+成本控制 | +20%~+25% |
| 基准 | 线性外推+中性假设 | +10%~+15% |
| 悲观 | 价格战+成本上涨+流失加速 | 0%~+5% |

**敏感性分析（双变量）：**
- 行：价格变动（-10% ~ +10%，步长5%）
- 列：销量变动（-20% ~ +5%，步长5%）
- 交叉格：EBITDA impact

### Step 6：验证与调整
**逻辑校验清单：**
- [ ] 利润率 > 100%？→ 必然有误（成本遗漏）
- [ ] 收入增长 > 市场增速2倍以上？→ 需有充分理由
- [ ] 现金流长期为负但无融资计划？→ 断裂风险
- [ ] 环比异常跳点？→ 检查历史数据口径是否一致

**与历史规律对比：**
```
历史平均毛利率：32%（±3%标准差）
预测毛利率：45% → ⚠️ 需说明定价权提升的具体依据
```

### Step 7：呈现与汇报
**一页预测摘要结构：**
```
【标题】2026年Q2-Q4 经营预测（基准情景）

【核心结论】
收入：+12%（+¥2400万）；EBITDA利润率：28%（+2pp）

【关键假设】（支持挑战）
1. 客户数：从12,000→14,400（+20%）
2. 毛利率：维持32%（原材料价格稳定假设）
3. 营销费率：12%（不增加投入前提）

【风险与备选】
· 风险：价格战导致毛利率降至28% → EBITDA-15%
· 情景：即使基准实现，现金流仍需¥800万融资补充

【触发条件】
若 [新客获取<预期80%]，立即启动悲观情景预算冻结
```

## 三、行业专精驱动因素速查

### 零售/快消
```
收入 = Σ(门店数 × 单店产出) + 电商渠道
     = 线下客流 × 转化率 × 客单价 + 线上复购 × 客单价

关键领先指标：进店客流、促销转化率、客单价变化
预警信号：客流量连续2周下降 → 本月收入大概率下滑
```

### 制造业
```
收入 = 产能利用率 × 产能上限 × 均价
     = (实际产量/设计产能) × 产能上限 × 均价

成本 = 固定成本（折旧+租金+管理）
     + 变动成本（原材料+直接人工+能耗）

关键领先指标：询盘量、订单backlog、供应商交期
预警信号：原材料库存骤降 → 生产即将放缓
```

### SaaS / 订阅制
```
MRR = 期末客户数 × 平均月订阅费
LTV = MRR / 月流失率
CAC = 营销费用 / 新增客户数
LTV/CAC > 3 → 健康；< 1 → 不可持续

关键领先指标：新增线索、免费转付费率、日活/周活
预警信号：月流失率突破2% → 年末MRR将腰斩
```

## 四、常见错误警示

| 错误 | 表现 | 后果 |
|------|------|------|
| 假设孤立 | 收入涨10%但成本不变 | 毛利必然失真 |
| 历史外推过度自信 | 用3年高增长预测未来3年 | 忽视市场天花板 |
| 忽略营运资本 | 收入涨了但现金流枯竭 | 资金链断裂 |
| 协同效应高估 | 并购预测节省20%成本 | 整合永远比预期难 |
| 模型复杂度陷阱 | 1000行Excel无人能维护 | 模型死亡 |
| 不设误差范围 | 给出单一数字而非区间 | 决策者过度信赖 |

## 五、CFO预测视角的核心原则

1. **先框架，后数字**——先确认驱动因素和假设逻辑，再填数字
2. **假设必须有人负责**——每一个数字背后要有业务负责人承诺
3. **误差比精确更重要**——±5%的区间预判，比±0.01%的点估计更有决策价值
4. **领先指标优先于滞后指标**——盯销售线索，不只看销售额
5. **模型要能被挑战**——让CEO能改假设跑情景，而不是看黑箱
6. **预测必须持续校准**——月度滚动更新，偏差>15%必须复盘归因
