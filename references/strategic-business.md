# 战略商业（翅膀）

> CFO的核心价值在于从财务视角驱动业务决策，成为CEO的战略伙伴。

---

## 1. 商业模式与行业知识

### 核心能力
- 深刻理解公司如何赚钱：成本结构、收入驱动因素、核心资产
- 行业财务标杆对标：毛利率、周转率、单位经济效益

### 商业模式分类与财务特征

| 模式 | 代表行业 | 关键财务特征 |
|------|---------|------------|
| 薄利多销 | 零售/快消 | 低毛利率、高周转率、规模效应 |
| 高研发驱动 | 医药/科技 | 高研发费用率、长回收期、高壁垒 |
| 资产周转驱动 | 物流/航空 | 重资产、高杠杆、现金流波动 |
| 平台网络效应 | 互联网 | 高边际利润、获客成本前置、赢家通吃 |
| 金融杠杆驱动 | 银行/保险 | 高杠杆、监管约束、风险定价为核心 |

### 非财务数据与财务的关联
- 用户数/点击率 → 获客成本/用户LTV
- 产能利用率 → 固定成本分摊/毛利率
- 客诉率 → 品牌溢价/退换货成本

## 2. 战略规划与资本配置

### 资本配置决策框架

```
可用资本
├── 有机增长（自研/扩产） → ROIC > WACC ?
├── 并购增长 → 协同效应 > 溢价 ?
├── 股东回报 → 分红/回购，增长放缓时首选
├── 债务偿还 → 杠杆率是否过高？
└── 战略储备 → 不确定性高的时期保留弹药
```

### 关键决策标准
- **ROIC vs WACC**：价值创造的核心判据
- **边际资本回报率**：每一元新增资本能带来多少回报
- **机会成本**：资本的唯一真正成本

## 3. 绩效管理与分析

### 核心体系
- 投资资本回报率（ROIC）= NOPAT / 投入资本
- 经济利润 = (ROIC - WACC) × 投入资本
- 与战略挂钩的KPI体系：分解到业务单元
- 滚动预测 vs 固定预算：敏捷vs控制
- 差异分析：量差/价差/结构差

### 绩效对话框架
```
1. 目标是什么？（战略分解）
2. 实际结果如何？（数据说话）
3. 差异原因是什么？（归因分析）
4. 下一步怎么办？（行动闭环）
```

## 4. 并购与整合

### 全流程能力

| 阶段 | 关键动作 | CFO核心关注 |
|------|---------|------------|
| 目标筛选 | 战略契合度初筛 | 财务指标筛选、估值区间 |
| 尽职调查 | 财务/税务/法务 | 隐藏负债、盈利质量、税务风险 |
| 交易结构 | 对价/支付/条款 | 对价合理性、支付方式税务影响 |
| 谈判 | 价格/条件/保护条款 | 估值底线、分手费、对赌 |
| 投后整合 | 系统/团队/文化 | 财务系统对接、协同效应验证 |

### 协同效应评估
- **收入协同**：交叉销售、定价权增强（估算需保守）
- **成本协同**：采购合并、人员优化（执行难度常被低估）
- **财务协同**：税盾、资本成本降低

### 并购陷阱
- 过度自信：协同效应高估50%+
- 整合低估：文化冲突、系统不兼容
- 竞价狂热：赢者诅咒

## 5. 投资者关系与资本市场

### 核心能力
- 向分析师/机构投资者讲述公司故事
- 管理市场预期：业绩指引的艺术
- 季报/年报发布策略
- 增发/上市/债券发行的核心角色

### 叙事框架
```
行业趋势 → 公司定位 → 竞争优势 → 财务验证 → 未来路径
（为什么现在？） （为什么我们？） （数据证明）  （持续多久？）
```

### 预期管理原则
- 低承诺、高交付
- 提前沟通坏消息，不搞惊喜
- 一致性比完美更重要
