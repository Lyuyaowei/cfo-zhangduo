# 净息差(NIM)分析模型

## 核心公式

```
NIM = 利息净收入 / 平均生息资产
利息净收入 = 利息收入 - 利息支出
```

## 息差驱动因素

```
NIM变化
├── 资产端
│   ├── 贷款定价（LPR ± 基点）
│   ├── 资产结构调整（高收益贷款占比）
│   ├── 投资配置（国债/地方债/信用债）
│   └── 重定价节奏（固定vs浮动）
├── 负债端
│   ├── 存款成本（活期/定期结构）
│   ├── 同业负债成本
│   ├── 央行借款利率
│   └── 主动负债管理
└── 政策端
    ├── LPR下调幅度
    ├── 存款利率自律机制
    └── 准备金率调整
```

## 息差收窄应对策略

### 短期（1年内）
- 压降高成本定期存款
- 提升高收益贷款投放（小微、消费贷）
- 加大债券配置择时力度

### 中期（1-3年）
- 提升中间业务收入占比（目标30%+）
- FTP精细化定价引导资源倾斜
- 数字化降本（降低成本收入比）

### 长期（3年+）
- 轻资本转型（投行、资管、财富管理）
- 表外业务拓展
- 综合金融服务生态构建

## 关键监控指标

| 指标 | 警戒线 | 说明 |
|------|--------|------|
| NIM | <1.5% | 低于此值盈利承压 |
| 存款成本率 | >2.0% | 负债端压力信号 |
| 贷款收益率 | <3.8% | 资产端收益不足 |
| 成本收入比 | >30% | 运营效率下降 |
